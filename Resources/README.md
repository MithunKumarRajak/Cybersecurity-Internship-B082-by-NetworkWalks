## 📝 Useful Commands Cheat Sheet

### Linux Basics

```bash
# System Information
uname -a                 # Kernel information
whoami                   # Current user
id                       # User ID and groups
ifconfig / ip a          # Network interfaces

# File Operations
ls -la                   # List files with details
cat /etc/passwd          # View users
find / -name "*.txt"     # Search for files
```

### Nmap Scanning

```bash
# Host Discovery
nmap -sn 10.0.0.0/24

# Port Scanning
nmap -sS -p- [target]        # TCP SYN scan all ports
nmap -sV [target]            # Version detection
nmap -A [target]             # Aggressive scan
nmap -sU [target]            # UDP scan
```

### Metasploit Basics

```bash
msfconsole                    # Start Metasploit
search [term]                 # Search for modules
use [module]                  # Select a module
show options                  # View module options
set RHOSTS [target]           # Set target
set LHOST [attacker_ip]       # Set listener
exploit / run                 # Execute
```
