## 📆 Weekly Projects

### 🗓️ Week 1 — Essentials: Cybersecurity & Pentesting Lab Setup

- Set up Kali Linux (hacker) + Windows (victim) + Android (victim - optional)
- Configure VirtualBox with NAT Network
- Verify connectivity between all VMs
- **Submission Deadline:** 23:59H, Monday 17-August-2026

### 🗓️ Week 2 — Footprinting, Scanning & Report Writing (Red Team - Offensive)

Choose **at least 1 elective** + both **essential** modules (minimum 3 total):

**Electives (choose ≥ 1):**
- W2-PM1: Footprinting with multiple Kali tools (6 tools on networkwalks.com)
- W2-PM2: GHDB-based Footprinting Attacks
- W2-PM3: Maltego-based Footprinting Attacks
- W2-PM4: theHarvester-based Footprinting Attacks

**Essentials (both required):**
- W2-PM5: Zenmap-based Network Scanning
- W2-PM-FINAL: Write a detailed Penetration Testing Report

- **Submission Deadline:** 23:00H, Friday 21-August-2026

### 🗓️ Week 3 — Cracking & Attacking (Red Team - Offensive)

- Phase 3/4 of Hacking on multiple targets
- Tools: John The Ripper (JTR), Metasploit, and more
- Multiple attack techniques and methodologies

### 🗓️ Week 4 — Full Pentest Project + SOC Track

**Offensive Track (Red Team):**
- Full Penetration Test covering ALL phases of hacking on a live target
- Write a comprehensive Pentest Report

**SOC Track (Blue Team):**
- Wireshark setup, capture traffic, analyze, and write a security report
