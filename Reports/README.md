## 📝 Report Templates

### Penetration Testing Report Template

1. **Cover Page**
   - Client Name / Target
   - Tester Name
   - Date of Testing
   - Confidentiality Classification

2. **Table of Contents**

3. **Executive Summary**
   - Brief overview for non-technical stakeholders
   - Key findings at a glance
   - Overall risk rating

4. **Scope & Objectives**
   - Systems/networks in scope
   - Testing methodology used
   - Rules of engagement

5. **Methodology**
   - Tools used
   - Testing approach (Black Box / White Box / Grey Box)
   - Phases followed

6. **Findings**
   - Organized by severity: Critical → High → Medium → Low → Informational
   - Each finding should include:
     - Title
     - Severity rating
     - Description
     - Evidence (screenshots, logs)
     - Impact assessment
     - Remediation recommendation

7. **Risk Assessment Matrix**

   | Severity | Count | Risk Level |
   |---|---|---|
   | Critical | | 🔴 |
   | High | | 🟠 |
   | Medium | | 🟡 |
   | Low | | 🟢 |
   | Informational | | 🔵 |

8. **Remediation Recommendations**
   - Prioritized action items
   - Short-term vs long-term fixes

9. **Conclusion**

10. **Appendices**
    - Raw scan outputs
    - Full screenshots
    - Tool configurations
